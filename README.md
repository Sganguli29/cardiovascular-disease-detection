## DETECTION OF CARDIOVASCULAR DISEASES USING ENSEMBLE LEARNING WITH RANDOM FOREST AND XGBOOST
DATASET USED : https://www.kaggle.com/datasets/mohamedhedidjemaa/ecgmitbit

A machine learning based project developed to analyze ECG data and assist in predicting possible heart disease conditions using deep learning techniques. This project was developed as a group academic project to explore the application of AI and deep learning in healthcare.
